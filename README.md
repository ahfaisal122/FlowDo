
# FlowDo

A minimal, dark-themed to-do list app for macOS — built with Electron.

No accounts. No cloud. No database. Just your tasks, stored locally on your Mac.

## Features

- Add, complete, and delete tasks
- Priority levels (High / Medium / Low)
- Categories (Work, Personal, Shopping, Health)
- Due dates with smart labels (Today, Tomorrow, Overdue)
- Desktop notifications for due and overdue tasks
- Filter by status, priority, or category
- Local JSON storage — your data never leaves your machine

## Tech Stack

- **Electron** — cross-platform desktop framework
- **HTML / CSS / JS** — single-file UI, no build tools
- **Node.js fs** — local file-based persistence
